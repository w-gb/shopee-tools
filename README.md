# Shopee 利润计算器

一个使用原生 HTML、CSS 和 JavaScript 构建的 Shopee 利润计算器网页，用于快速估算商品毛利润、净利润和利润率。

## 功能

- 输入商品成本、国内运费、国际运费、平台佣金比例、广告费和售价。
- 实时计算毛利润、净利润和利润率。
- 响应式布局，适配桌面端和移动端。
- 无需构建工具，直接打开 `index.html` 即可使用。

## 计算公式

```text
毛利润 = 售价 - 商品成本 - 国内运费 - 国际运费
平台佣金 = 售价 × 平台佣金比例
净利润 = 毛利润 - 平台佣金 - 广告费
利润率 = 净利润 ÷ 售价
```

## 本地运行

直接在浏览器中打开 `index.html`，或使用任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。
